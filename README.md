# سيبويه — منصة اللغة العربية

تطبيق أندرويد تجريبي + واجهة طالب عربية + لوحة إدارة ويب، بهوية أسود وذهبي وعاجي، مع صورة وهوية مصطفى عبدالفضيل الشعار المعتمدة.

## الموجود في النسخة 0.1

- تسجيل الاسم والهاتف والصف والإيميل وكلمة المرور، مع حالة انتظار التفعيل.
- رسالة واتساب جاهزة ببيانات الطالب والكورس؛ الطالب يرسلها بنفسه. لا يوجد تفعيل تلقائي بسبب فتح واتساب.
- كورس دراسي واحد لكل صف يضم جميع الأقسام. الاشتراك **٣٠ يومًا** بتفعيل الإدارة بعد الدفع.
- التجديد المبكر يضاف للمدة المتبقية؛ بعد الانتهاء يبدأ من لحظة التجديد. حماية من تكرار نفس طلب التجديد.
- قسم **طور نفسك**: كورسات مستقلة وتفعيل مستقل، مع مدة تختارها الإدارة.
- إضافة وتعديل وإخفاء الكورسات والمحاضرات، ترتيبها، ملاحظات ورابط ملزمة.
- مصادر فيديو: YouTube، معاينة Google Drive، MP4، HLS، Cloudflare Stream خاص، وملفات MP4 في R2 الخاص.
- متابعة موضع التوقف في MP4/HLS/R2/YouTube؛ إتمام الدرس يدويًا لجميع المصادر. لا يوجد API لموضع توقف معاينة Drive في هذه النسخة.
- تقارير التقدم، جلسات مشاهدة وكود حساب/جلسة، تفعيل وإلغاء وإيقاف حساب، بحث بالاسم والإيميل والهاتف والكود.
- جلسة دخول واحدة للطالب: تسجيل الدخول من جديد ينهي جلسة الطالب السابقة.
- تحقق من الاشتراك من الخادم قبل إصدار المصدر، ومراجعة صلاحية الجلسة كل ١٥ ثانية أثناء تشغيل الصفحة.

## تشغيل محلي على Windows / Linux

Python 3.12 مطلوب على جهاز الإدارة أو السيرفر. التثبيت التالي للخادم، وليس شرطًا على جهاز الطالب.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
python -m server.app create-admin --email YOUR_EMAIL
python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
```

Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python -m server.app create-admin --email YOUR_EMAIL
python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
```

إنشاء المدير يطلب كلمة مرور سرية في الطرفية (١٢ حرفًا على الأقل)، ولا يوجد حساب مدير افتراضي أو كلمة مرور ثابتة.

افتح `http://127.0.0.1:8000/admin` للإدارة، و`http://127.0.0.1:8000` للطالب. في الإعدادات أدخل رقم واتساب دوليًا، مثل `201xxxxxxxxx` بدون `+`. الحساب الدراسي لا يتفعّل إلا بزر «تأكيد الدفع وتفعيل الاشتراك».

### نشر فعلي

الخادم يحتاج جهازًا دائم التشغيل ورابط HTTPS. **GitHub يحفظ الكود ويبني APK؛ لا يشغّل قاعدة البيانات أو البانل.** لا تستخدم GitHub Pages لخادم التطبيق. يمكن استخدام سيرفر موجود لديك بدل شراء استضافة جديدة.

1. انسخ `.env.example` إلى `.env` على الخادم، واضبط `PUBLIC_URL` على أصل رابط HTTPS الفعلي بدون مسار أو `/` أخيرة.
2. `docker compose up -d --build`.
3. `docker compose exec app python -m server.app create-admin --email YOUR_EMAIL`.
4. وجّه reverse proxy بــTLS إلى `127.0.0.1:8000`. لا تنشر منفذ uvicorn مباشرة للإنترنت؛ لا توجد ثقة تلقائية في forwarded headers.
5. احفظ نسخة احتياطية من volume `sibawayh_data`، واختبر استعادتها. هذه النسخة تستخدم SQLite؛ راجع القياس قبل إطلاق كبير.

## أندرويد

مشروع Java أصلي خفيف يغلف واجهة الخادم في WebView، وليس مشروع Flutter أو تطبيق iOS. Android 8+، Target API 35.

GitHub Actions يشغّل اختبارات الخادم ثم يبني **APK تجريبي** في artifact اسمه `Sibawayh-Android-Trial`. تنزيله من تبويب Actions، ثم فك ZIP وتثبيت APK. النسخة موقعة بمفتاح debug من بيئة البناء؛ ليست إصدار المتجر ولا مفتاحًا ثابتًا للتحديثات. إصدار المتجر يحتاج توقيعك وإعداد حساب النشر.

أول فتح يطلب رابط خادم HTTPS الذي أعددته. لا تدخل بيانات حقيقية على رابط مجهول. لتغيير عنوان النسخة التجريبية امسح بيانات التطبيق من إعدادات أندرويد أو اضغط مطولًا على رسالة شاشة الحماية ثم أدخل العنوان الجديد. تغيير الرابط يمسح cookies والكاش. يمكن تثبيت العنوان داخل إصدار نهائي بعد اعتماد الخادم.

البناء محليًا: Android SDK 35، JDK 17 وGradle 8.11.1، ثم:

```bash
gradle -p android :app:assembleDebug :app:lintDebug
```

## الحماية: ما هو منفّذ وحدوده

| الخاصية | التنفيذ وحدودها |
|---|---|
| اشتراك ٣٠ يومًا | مفروض من الخادم. إلغاء الاشتراك يوقف صفحة المشاهدة خلال ١٥ ثانية، ولا يلغي رابط فيديو عام خارج المنصة. |
| لقطة / تسجيل الشاشة | `FLAG_SECURE` في أندرويد، ويظل مفعّلًا في ملء الشاشة. ليس ضمانًا ضد جهاز معدل أو كاميرا خارجية. |
| السماعة | فحص أجهزة إخراج سلك/USB/بلوتوث المتصلة، ومراجعة كل ٦٠٠ مللي ثانية. لا يثبت أنها في الأذن، ولا يثبت مسار الصوت النشط على كل جهاز. يلزم اختبار فعلي. |
| VPN / البروكسي | كشف VPN الذي يظهر لواجهات أندرويد والبروكسي الافتراضي، ثم إزالة صفحة المشاهدة وإظهار طلب إغلاقه. لا يمنع تشغيل برامج أخرى على الجهاز، ولا يكشف كل نفق خارجي أو جهاز معدل. |
| HTTP Canary | لا يوجد ادعاء بكشف التطبيق بالاسم. الكشف قائم على VPN/Proxy وتأمين TLS، ونسخة الإنتاج لا تثق بشهادات المستخدم. لا توجد حماية مطلقة من اعتراض جهاز مخترق. |
| الكود الشخصي | علامة متحركة فوق فيديو MP4/HLS/R2، وداخل ملء شاشة حاوية المشغّل. في YouTube/Drive/Stream الكود **خارج مساحة المشغّل**، فلا يغطي الصورة أو أزرار مقدم الخدمة؛ لا تدّعي هذه النسخة تتبع تصوير تلك الفيديوهات بكاميرا خارجية. |
| YouTube | مشغله الرسمي المضمن؛ لا حذف لعلامته أو تعطيل لروابطه المطلوبة، ولا ضمان لحصر الرابط داخل التطبيق. |
| Google Drive | معاينته الرسمية المضمنة، وقد تحتاج Google login وcookies وتخضع لحدود مشاهدة. قفل حسابنا لا يلغي صلاحيات Drive. |
| روابط مباشرة | الرابط العام يعمل خارج التطبيق أيضًا. لا استخراج لروابط YouTube أو Drive الخام. |
| R2 الخاص | مفاتيح الخادم فقط، روابط MP4 موقعة لمدة ٥ دقائق، تتجدد داخل الصفحة كل ٤ دقائق بعد فحص الاشتراك. ليست DRM، ويمكن استخدام الرابط المنسوخ خلال صلاحيته. اضبط CORS على أصل التطبيق. |
| Stream الخاص | الفيديو يجب أن يشترط Signed URL في Cloudflare. يُصدر الخادم token لمدة ٤ ساعات للجلسة الطويلة. رابط منسوخ قد يظل صالحًا حتى نهايته؛ ليس DRM أو app-only. Stream مدفوع. |
| تقارير الجهاز | معلومات يرسلها التطبيق، وليست دليلًا قطعيًا. لا حظر دائم تلقائي بسبب VPN أو تقرير الجهاز. |

## إعداد مصادر Cloudflare

في `.env` على الخادم فقط:

- Stream: `CF_ACCOUNT_ID` و`CF_STREAM_TOKEN` بصلاحيات إصدار token؛ اجعل الفيديو خاصًا (`requireSignedURLs`) من Cloudflare. في البانل استخدم معرّف الفيديو (٣٢ حرفًا).
- R2: `CF_ACCOUNT_ID` و`R2_ACCESS_KEY_ID` و`R2_SECRET_ACCESS_KEY` بصلاحية قراءة الحاوية و`R2_BUCKET`. الحاوية خاصة، وفي البانل اكتب مفتاح ملف MP4 مثل `lessons/lesson1.mp4`. ارفع Content-Type الصحيح، واضبط CORS لـGET/HEAD وRange عند الحاجة. لا يُدعم HLS خاص داخل R2 بهذه الآلية؛ manifest وحده لا يوقّع روابط المقاطع.
- بدون تلك المفاتيح، يعرض الخادم خطأ إعداد واضحًا، ولا يجعل الملفات عامة تلقائيًا.

## الاختبارات وحالة التسليم

```bash
python -m unittest discover -s tests -v
node --check server/static/app.js
```

اختبارات حقيقية للتسجيل والأدوار وCSRF، تجديد ٣٠ يومًا وإعادة الطلب، انتهاء/إلغاء الاشتراك أثناء جلسة، الصفوف، وفصل طور نفسك، وحفظ التقدم، وقفل الحساب والتحقق من المصادر.

النسخة الأولى تحتاج إعداد الخادم ورقم واتساب ومحتوى دروسك. الاختبارات والواجبات الدراسية، استعادة كلمة المرور الذاتية، الإشعارات، والتوزيع النهائي على المتجر **ليست ضمن التنفيذ الحالي**. لا توجد مفاتيح خدمات أو بيانات طلبة حقيقية في المستودع.

يجب اختبار APK فعليًا على أندرويد مع سماعات سلك/بلوتوث، VPN وHTTP Canary، ملء الشاشة والخلفية، وYouTube/Drive على الحسابات المستهدفة قبل فتحه للطلبة. البناء الناجح وحده لا يثبت سلوك هذه الحالات أو ثبات تشغيل المصادر الخارجية.
